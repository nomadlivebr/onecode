## Platform

web

## Users

Donos e gestores de pequenas e médias empresas que não possuem um time de TI interno. São pessoas que entendem que precisam de presença digital e tecnologia para crescer, mas não têm tempo, conhecimento técnico ou estrutura para gerenciar isso por conta própria. Buscam um parceiro de confiança que assuma essa responsabilidade de forma contínua.

## Product Purpose

A One Code Tecnologia é uma agência de desenvolvimento que atua como departamento de tecnologia terceirizado para PMEs. O produto central não é a entrega de um site ou sistema — é a parceria contínua mensal: construir, lançar e manter a presença digital da empresa do cliente em constante evolução. Sucesso significa que o cliente não precisa mais se preocupar com tecnologia; a One Code cuida de tudo.

## Positioning

A diferença que uma agência concorrente ou um freelancer não pode copiar de verdade: a One Code não entrega e desaparece. O modelo de assinatura mensal garante que o projeto continue vivo, seguro, atualizado e recebendo novas funcionalidades todo mês — transformando tecnologia de custo esporádico em investimento previsível e contínuo.

## Operating Context

O visitante chega à landing page geralmente via indicação, redes sociais, ou busca orgânica. Está avaliando se a One Code é confiável e se o modelo de parceria faz sentido para o negócio dele. A decisão de compra não é imediata — envolve uma conversa (WhatsApp ou formulário de contato) antes de fechar. A landing page precisa gerar confiança, explicar o modelo e capturar o lead.

## Product Principles

1. **Parceria, não entrega:** cada interação de design e copy deve reforçar que a One Code é um sócio de tecnologia de longo prazo, não um fornecedor de projetos pontuais.
2. **Confiança antes da conversão:** PMEs compram de quem elas confiam. Cada seção deve construir credibilidade antes de pedir ação.
3. **Clareza para o não-técnico:** o visitante é um gestor, não um desenvolvedor. Linguagem simples, benefícios concretos, sem tech-speak.
4. **Previsibilidade como proposta de valor:** o modelo de assinatura resolve a dor de custos imprevisíveis de TI — isso deve aparecer com força no design.
5. **Presença viva:** o site da própria One Code deve parecer a melhor demonstração do que ela faz — rápido, responsivo, visualmente impecável.
